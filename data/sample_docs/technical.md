# Technical Support Guide

## Data Export
To export data to CSV: go to Settings → Data → Export → Select format → Download.
Exports are generated asynchronously and emailed when ready for large datasets.
CSV exports include all records from the selected date range.

## Login Issues
If a user cannot log in, first check if the account is active and not suspended.
Password reset emails expire after 24 hours.
For SSO users, contact the organization admin to reset access.

## API Integration
API keys are generated in Settings → Developer → API Keys.
Rate limits are 1000 requests per hour on the free plan, 10000 on paid plans.
API documentation is available at docs.yourproduct.com.
